# StockVision Pro 📈

A professional-grade stock market analysis dashboard built with Streamlit and Yahoo Finance.

## Features
- **Live Market Ticker:** Scrolling real-time market data for major indices.
- **AI Analyst Verdict:** Machine-learning based price predictions and technical summaries.
- **Lottie Animations:** Smooth, classy visual transitions.
- **Secure Authentication:** User login and registration system using SQLite.
- **Real-time Data:** Live stock prices, volume, and company fundamentals via `yfinance`.
- **Advanced Technical Analysis:** Candlestick charts, SMA, EMA, Bollinger Bands, RSI, MACD, and VWAP.
- **AI-Powered Signals:** Composite technical scoring for "Buy/Sell" indicators.
- **Sentiment Analysis:** Real-time news sentiment tracking.
- **Market Insights:** CNN Fear & Greed Index integration and Sector Heatmaps.
- **Interactive Tools:** Watchlist management, custom alerts, and peer correlation matrices.

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/stokapp.git
   cd stokapp
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Run the application:
   ```bash
   streamlit run app.py
   ```

## Technologies
- **Python** (Core Logic)
- **Streamlit** (UI Framework)
- **Plotly** (Interactive Charts)
- **Pandas** (Data Manipulation)
- **TA-Lib (ta)** (Technical Analysis)
- **TextBlob** (Sentiment Analysis)
- **SQLite** (User Database)
